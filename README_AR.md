# بوت السيرفر — الفعاليات + التذاكر + الحضور والموظفين

هذه النسخة مطورة من بوت فعالية الموارد الأصلي، وتحافظ على قراءة صور الموارد مع إضافة أنظمة التذاكر والحضور والموظفين ولوحة إعدادات واحدة.

## الصلاحية الكاملة
الحساب صاحب الآيدي التالي لديه تحكم كامل بالبوت دائمًا حتى بدون رتبة:
`766300799332122624`

يمكن تغيير الآيدي لاحقًا من `BOT_OWNER_ID` داخل `.env` إذا احتجت.

## لوحة الإعدادات
استخدم:
`/settings`

اللوحة تظهر **Ephemeral** للإداري الذي فتحها فقط، ومنها تستطيع إدارة:
- الفعاليات.
- التذاكر.
- الدخول والخروج.
- الموظفين.
- رتب إدارة البوت.

---

## 1) نظام الفعاليات

### إنشاء فعالية
استخدم `/إنشاء_فعالية` وحدد:
- اسم الفعالية.
- رسالة لوحة الفعالية.
- شروط الفعالية.
- روم لوحة الفعالية.
- روم المتصدرين الثابتة.
- روم لوق صور الموارد.
- رابط صورة اختياري.

يمكن تعديل النص والشروط والصورة وأسماء الأزرار والرومات أيضًا من `/settings` > إعدادات الفعاليات.

### دخول المشارك
في لوحة الفعالية يوجد زر **دخول الفعالية**.
عند الضغط عليه تظهر الشروط بشكل خاص، ولا يتم تسجيل العضو إلا بعد الضغط على **موافق على الشروط**.
بعدها يستطيع استخدام زر **حساب الموارد**.

### حساب الموارد
النظام يحافظ على نفس طريقة البوت السابق:
1. العضو يضغط حساب الموارد.
2. يرسل الصورة خلال 90 ثانية.
3. البوت يرسل نسخة إلى روم اللوق ويحذفها من روم المشاركة.
4. يقرأ قيم Owned للموارد الثمانية.
5. يعرض النتيجة للعضو لاعتمادها أو إلغائها.
6. بعد الاعتماد تتحدث لوحة المتصدرين الثابتة مباشرة.

### إنهاء الفعالية
`/إنهاء_الفعالية`

بعد التأكيد:
- تحفظ النتائج النهائية في قاعدة البيانات.
- يتوقف استقبال المشاركات.
- تتصفر نقاط الجميع.
- تتحدث لوحة المتصدرين وتعود فارغة للفعالية التالية.

أوامر الإدارة القديمة المدعومة:
- `/بداية_الفعالية`
- `/لوحة`
- `/احصائيات`
- `/اضافة`
- `/خصم`

## 2) نظام التذاكر

من `/settings` > إعدادات التذاكر تستطيع:
- تحديد عنوان ونص وصورة لوحة التذاكر.
- تحديد روم لوحة التذاكر.
- تحديد روم اللوق.
- إضافة أنواع تذاكر جديدة أو حذفها.
- تعديل اسم النوع والوصف والإيموجي ورسالة الترحيب.
- تحديد Category مستقلة لكل نوع.
- تحديد رتب الإدارة التي تشاهد النوع.
- تفعيل أو إيقاف النوع.
- تحديد أسئلة النوع، كل سؤال في سطر، حتى 5 أسئلة.

الأنواع الافتراضية:
- تقديم.
- استفسارات.

اللوحة تستخدم قائمة اختيار مثل التصميم المطلوب. عند اختيار نوع يحتوي أسئلة، تظهر الأسئلة أولًا، وبعد الإجابة تنفتح التذكرة وتظهر الإجابات بداخلها.

كل تذكرة تحتوي زر إغلاق، ويمكن لصاحب التذكرة أو إدارة النوع أو إدارة البوت إغلاقها.

---

## 3) نظام تسجيل الدخول والخروج

من `/settings` > الدخول والخروج تحدد:
- رتبة/رتب الموظفين.
- رتبة/رتب الإدارة.
- روم لوحة الدخول والخروج.
- روم حالة الموظفين.
- روم لوحة الموظفين والساعات.
- روم اللوق.
- عنوان ونص وصورة لوحة الحضور.

لوحة الحضور تحتوي 4 أزرار:
- 🟢 دخول.
- 🔴 خروج.
- 😴 غفوة: أول ضغطة تبدأ الغفوة وتوقف احتساب الوقت، والضغط مرة ثانية ينهي الغفوة ويعيد احتساب الوقت.
- ⛔ خروج إجباري: يعمل للإدارة فقط ويطلب اختيار الموظف.

يوجد Embed ثابت لحالة الموظفين يعرض:
- المسجلين دخول حاليًا.
- الموجودين في غفوة.

---

## 4) لوحة الموظفين

لوحة ثابتة تعرض تلقائيًا كل عضو يحمل رتبة الموظف المحددة، وبجانبه:
- إجمالي ساعات المباشرة.
- حالة دخول أو غفوة عند وجودها.
- الملاحظة الإدارية إن وجدت.

تتحدث اللوحة عند الدخول والخروج والغفوة وتغيير الرتبة، كما يحدثها البوت دوريًا أثناء التشغيل.

### الملاحظات
`/ملاحظة`
- اختر الموظف.
- اكتب الملاحظة لتظهر بجانب اسمه.
- إذا تركت الملاحظة فارغة يتم حذفها.

### إرسال رسالة للموظف
`/رسالة_موظف`
- اختر الموظف بالمنشن من خيار الأمر.
- اكتب الرسالة.
- عنوان اختياري.

يرسل البوت الرسالة له في الخاص ويسجل العملية في روم لوق الموظفين. إذا كان الخاص مغلقًا يخبر الإداري أن الإرسال تعذر.

## التشغيل

```cmd
python -m pip install -r requirements.txt
python bot.py
```

عند أول تشغيل ستتم إضافة الجداول الجديدة تلقائيًا داخل نفس `resources.db` بدون حذف بيانات البوت القديمة.

## أول إعداد مقترح
1. شغل البوت.
2. استخدم `/settings`.
3. اضبط الفعاليات والتذاكر والحضور والرتب والرومات.
4. من كل قسم اضغط **نشر/تحديث** لإنشاء اللوحات الثابتة.


## نظام المخازن

من `/settings` اختر **إعدادات المخازن**. يمكنك تحديد روم اللوحة، تعديل عنوان/نص/صورة اللوحة، وإضافة حتى 20 مستودعًا. اسم المستودع هو نفسه اسم الزر.

لوحة المخازن تعرض لكل مستودع الموارد الثمانية: Steel, Aluminum, Rubber, Metalscrap, Iron, Plastic, Copper, Glass **من دون عرض المجموع**. عند الضغط على زر مستودع وإرسال صورة جديدة، يقرأ البوت قيم Owned ويستبدل بيانات ذلك المستودع القديمة بالكامل بالقيم الجديدة ثم يحدث اللوحة الثابتة تلقائيًا.
