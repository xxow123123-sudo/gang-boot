# بوت السيرفر — نسخة Multi‑Server

هذه النسخة تدعم الفعاليات، التذاكر، المخازن، الحضور والموظفين، ونظام الورش. كل سيرفر يدخل فيه البوت يعمل بإعدادات وبيانات مستقلة عن أي سيرفر آخر.

## الاستقلال بين السيرفرات

البوت ينشئ قاعدة بيانات مستقلة لكل سيرفر تلقائيًا باسم قريب من:

`resources_<GUILD_ID>.db`

وبذلك تكون إعدادات الفعاليات والتذاكر والحضور والمخازن والورش والنقاط والساعات مستقلة لكل سيرفر.

عند ترقية النسخة القديمة، يحاول البوت اكتشاف السيرفر الرئيسي القديم من الرومات المحفوظة وينسخ `resources.db` له مرة واحدة حتى يحافظ على البيانات السابقة قدر الإمكان.

## لوحة pilot الخاصة

مالك البوت الافتراضي:

`766300799332122624`

الأمر:

`/pilot`

اللوحة **Ephemeral** ولا يراها إلا pilot، وتعرض:
- حالة البوت.
- Ping.
- عدد السيرفرات.
- جميع السيرفرات التي دخلها البوت مع ID وعدد الأعضاء وحالة الاتصال.
- زر تحديث.

إذا استخدم شخص آخر الأمر يظهر له:

`هذا الأمر لـ pilot فقط.`

يمكن تحديد السيرفر الرئيسي صراحة داخل `.env`:

`PILOT_GUILD_ID=SERVER_ID`

ويمكن تغيير مالك البوت عبر:

`BOT_OWNER_ID=USER_ID`

## لوحة الإعدادات

`/settings`

اللوحة Ephemeral للإدارة وتتحكم فقط في إعدادات **السيرفر الحالي**:
- الفعاليات.
- التذاكر.
- المخازن.
- الورش.
- الدخول والخروج.
- الموظفين.
- رتب إدارة البوت.

## نظام التذاكر

لوحة التذاكر أصبحت تعتمد على **أزرار** بدل حصرها في تقديم واستفسارات.

من `/settings` > إعدادات التذاكر تستطيع:
- إضافة زر تذكرة بأي اسم تريده.
- اختيار الإيموجي والوصف ورسالة الترحيب.
- كتابة أسئلة الزر أثناء إنشائه، كل سؤال في سطر، حتى 5 أسئلة.
- تعديل الأسئلة لاحقًا.
- تحديد Category مستقلة لكل زر.
- تحديد رتب الإدارة التي تشاهد التذكرة.
- تفعيل/إيقاف أو حذف أي زر.
- تحديد روم اللوحة وروم اللوق.

النوعان القديمان (تقديم واستفسارات) يبقيان قابلين للتعديل أو الحذف، ويمكن إنشاء أي أنواع إضافية.

## نظام الورش

من `/settings` > **نظام الورش** تحدد:
- روم لوحة الورش الثابتة.
- روم لوق صور الورش.
- روم لوحة أكثر المتفاعلين الثابتة.
- عنوان ونص وصورة لوحة الورش.

لوحة الورش فيها زر **تسجيل خدمة**. عند الضغط يختار الموظف:

1. **تعديل مركبة**
   - يجب تحديد نوع التعديل: `Full Stage` أو `أخرى`.
   - يطلب البوت صورة الفاتورة.
   - ثم يطلب صورة السيارة.
   - يحذف الصور من روم الاستخدام بعد استلامها ويرسل نسخًا إلى روم اللوق.
   - يسجل العملية ويحدث لوحة أكثر المتفاعلين.

2. **بيع عدة تصليح**
   - يطلب صورة الفاتورة.
   - يرسلها للوق ويسجل العملية ويحدث الترتيب.

كل عملية معتمدة تحتسب **خدمة واحدة** في ترتيب أكثر المتفاعلين.

### تصفير الورش

الأمر:

`/تصفير_الورش`

يطلب تأكيدًا ثم يصفر ترتيب الورش. رسائل اللوق القديمة لا يتم حذفها.

ويوجد زر تصفير أيضًا داخل إعدادات الورش.

## نظام تسجيل الدخول والخروج

من `/settings` > الدخول والخروج تحدد:
- رتبة/رتب الموظفين.
- رتبة/رتب الإدارة.
- روم لوحة الدخول والخروج.
- روم حالة الموظفين.
- روم لوحة الموظفين والساعات.
- روم اللوق.
- عنوان ونص وصورة لوحة الحضور.

لوحة الحضور تحتوي:
- 🟢 دخول.
- 🔴 خروج.
- 😴 غفوة.
- ⛔ خروج إجباري للإدارة.

### تصفير الحضور

الأمر:

`/تصفير_الحضور`

بعد التأكيد:
- تصفر ساعات جميع الموظفين في السيرفر الحالي.
- تنتهي جميع جلسات الدخول والغفوة الحالية.
- تتحدث لوحات الحالة والموظفين.

ولا يتم حذف الملاحظات الإدارية للموظفين.

يوجد زر تصفير أيضًا داخل إعدادات الحضور.

## نظام الفعاليات

الأوامر الرئيسية:
- `/إنشاء_فعالية`
- `/بداية_الفعالية`
- `/إنهاء_الفعالية`
- `/لوحة`
- `/احصائيات`
- `/اضافة`
- `/خصم`

كل فعالية ونقاطها ولوحاتها مستقلة لكل سيرفر.

## نظام المخازن

من `/settings` > إعدادات المخازن تستطيع إضافة حتى 20 مستودعًا وتحديد روم اللوحة وعنوانها وصورتها.

كل مستودع يعرض الموارد الثمانية بدون مجموع، وأي صورة جديدة تستبدل بيانات المستودع السابقة بالكامل. المخازن مستقلة لكل سيرفر.

## الصلاحيات المطلوبة

- Read Message History

ومن Discord Developer Portal فعّل:
- Message Content Intent

## التشغيل

```cmd
python -m pip install -r requirements.txt
python bot.py
```

## أول إعداد مقترح

1. شغل البوت.
2. استخدم `/settings` داخل كل سيرفر واضبط إعداداته الخاصة.
3. حدد رومات التذاكر والحضور والمخازن والورش.
4. اضغط نشر/تحديث من كل قسم.
5. استخدم `/pilot` في سيرفرك الرئيسي للتأكد من حالة البوت والسيرفرات.
